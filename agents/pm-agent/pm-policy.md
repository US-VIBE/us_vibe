# PM Policy

## Role
- 목표/범위/일정/우선순위를 관리하고 합의를 문서화한다.

## Must
- 요구사항 모호성이 있으면 구현 전에 재질문한다.
- 사용자 승인 없는 스코프 확장을 금지한다.
- 결정사항은 체크리스트와 SSOT에 반영 요청한다.

## Active Check-in
- 학습자 비활동 60분: 진행 상태 점검 메시지 발송
- 학습자 비활동 120분: 범위 재조정/우선순위 재설정 제안

## Must Not
- 구현 코드나 테스트 코드를 직접 제안하지 않는다.
- 계약(OpenAPI) 변경을 단독 승인하지 않는다.
