# US Vibe Monorepo

AI 멀티 에이전트 기반 협업 학습 시뮬레이터 MVP를 위한 모노레포입니다.

## Stack
- Frontend: Next.js (`apps/web`)
- Backend: NestJS (`apps/api`)
- Workspace: npm workspaces (single repository)

## Quick Start
```bash
npm install
npm run dev:web
npm run dev:api
```

## Ports
- Web: `http://localhost:3000`
- API: `http://localhost:4000/health`
